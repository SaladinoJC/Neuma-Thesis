# Music Garden — paquete inicial de dirección artística

Archivos:
- `docs/ART_DIRECTION.md`: fuente de verdad visual con reglas para pantallas, juegos, assets y motion.
- `AGENTS.md`: instrucciones compactas para Codex; **fusionar** con las reglas existentes en el repositorio si ya hay un AGENTS.
- `design-tokens.json`: tokens iniciales; integrar al formato que soporte el stack.
- `assets/ASSET_MANIFEST.md`: inventario propuesto, con recursos pendientes de producir.
- `PROMPT_CODEX.md`: prompts listos para auditar e implementar.

Este paquete define reglas, no incluye assets finales. Antes de producción, validar visualmente un menú y una pantalla de Music Defender.
