# Android como plataforma objetivo

El usuario confirmó el 2026-10-02 que el proyecto se desarrollará siempre para Android. Frente a la alternativa de comenzar con una versión web y trasladar después los juegos, se adopta Android desde el primer incremento, en consonancia con la orientación móvil del protocolo. Esta decisión fija la plataforma; el framework de interfaz y las APIs de audio todavía no están elegidos.
