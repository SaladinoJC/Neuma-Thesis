# Capturas de A5

Evidencia propia de Android Compose, Pixel_6/API 34, con estimaciones sintéticas en el límite de captura. No son mediciones de guitarra ni assets de la aplicación.

- `final-411/`: versión final, 411 dp/texto 100 %.
- `360/`: versión final, 360 dp/texto 100 %.
- `320-texto200/`: versión final, 320 dp/texto 200 %.
- `411/`: primera muestra de esta sesión, anterior a corregir selectores y adelantar el resumen; conservar como antecedente, no como entrega vigente.

Cada carpeta final contiene preparación, corrección, siguiente cuerda con medición oculta y resumen. El caso activa clasificación previa para verificarla; en un perfil nuevo está desactivada. Se muestran seis intentos, un error inicial de +30 cents corregido y revisión final completa. Las capturas representan una posición de scroll, no toda la página.
