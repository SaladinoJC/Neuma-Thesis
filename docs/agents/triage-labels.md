# Triage labels

| Rol | Etiqueta | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Requiere evaluación |
| needs-info | needs-info | Falta información |
| ready-for-agent | ready-for-agent | Especificado para ejecución por un agente |
| ready-for-human | ready-for-human | Requiere implementación humana |
| wontfix | wontfix | No se realizará |

Usar la etiqueta correspondiente cuando una skill mencione un rol.
